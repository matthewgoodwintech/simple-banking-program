# Simple Banking Program

This is a beginner Python banking project created while learning programming fundamentals and basic software logic.

The program allows users to:

* Check account balance
* Deposit money
* Withdraw money
* Prevent withdrawals when funds are too low
* Exit the banking system safely

---

## Features

* Menu-based banking system
* Deposit functionality
* Withdrawal functionality
* Insufficient funds protection
* Balance tracking
* Continuous program loop until user exits
